# 台灣人的生活大小事指南

這是一份以台灣生活情境編寫的實用指南，整理健康、金錢、法律、家庭、工作和日常安全等大小事。

內容參考 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 的分章方式、成本／收益欄位和證據分級。原書使用 CC BY 4.0。這份改編版保留來源署名，並重新查核台灣法規、政府服務和生活資訊。原書正文最後同步版本為 `bb25081`，下載日期為 2026-10-10。

## 閱讀方式

- 每條建議寫明成本、能得到什麼、證據等級與來源。
- 法律、補助、費率、資格和服務電話會標上查核日期；遇到縣市差異時會指出要查哪個地方政府。
- A 代表條文或原始研究可查，B 代表有可靠資料但仍有限制，C 代表實務提醒或經驗建議。A 不等於效果一定適用每個人。
- 這是一般資訊，不取代醫療診斷或個案法律意見。遇到急症請先打 119；法律權益依個案事實確認。
