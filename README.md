# 台灣人的生活大小事指南

以台灣的法規、政府服務和日常情境，整理健康、金錢、法律、家庭、工作與生活安全。閱讀頁共 35 章：第 1 章為台灣日常生活導覽；第 2 至 35 章沿用原作 34 章主題逐條改寫 676 條，另有 9 條台灣新增建議，全頁共 692 條閱讀內容。

## 閱讀前請留意

- 不必照單全收；依自己的情況挑需要的建議。
- 法規、補助、資格、費率與服務方式可能改變；辦理前請依文件所列日期，到主管機關或所在地政府確認。
- 本指南提供一般資訊，不取代醫療診斷、法律意見或個案服務。遇到急症請打 119。
- 台灣各縣市作法可能不同，內容會標示地方差異與查詢入口，不把單一地區的規定當成全台通用。
