# 台灣版編輯原則

## 範圍

本版主要寫給在台灣生活的人。法規以中華民國現行法規為準，行政服務以中央機關與地方政府公告為準。碰到直轄市、縣市或鄉鎮市區規定不同的題目，正文會提醒讀者查居住地規定，不把單一縣市的做法說成全台通用。

「台灣人的生活」不是單一習慣。都市、鄉鎮、離島、原住民族部落、不同家庭型態與新住民的生活條件都不同。內容用可查證的規則和具體情境來寫，不替所有人概括生活方式。

## 條目格式

每條建議盡量包含：

- 建議：以可以執行的動作開頭。
- 成本：要花的錢、時間和持續力。
- 說人話：先用一兩句話講清楚誰該做什麼。
- 收益：說清楚能避免的損失或得到的保障，不把相關性寫成因果。
- 證據等級：A、B 或 C，與性價比判斷分開。
- 來源：優先列法規原文、政府機關資料、原始研究或專業指引。
- 備註：寫適用對象、例外、地方差異和資料日期。

法律類 A 級只表示引用到現行法規或官方說明，不代表爭議結果必然有利。條文要核對修正日期、生效日和授權子法。已公布但尚未生效的條文，不能當成現行規定。

## 台灣在地化檢查

1. 把人民幣、社保、戶籍制度、電話號碼、機關名稱和中國大陸法規逐項換成台灣資料，不做字面替換。
2. 先分清中央法規、地方自治規則、政府服務和私人機構作法。
3. 民生數字附上適用年度。最低工資、補助、保費、票價、篩檢資格和電話服務時間都需要定期重查。
4. 垃圾清運、租屋補助、托育、急難救助等服務可能依縣市或個人資格不同，正文要附地方查詢入口。
5. 不用「台灣人都會」或「台灣人通常」代替證據。飲食、交通、照顧和居住情境要寫明適用條件。
