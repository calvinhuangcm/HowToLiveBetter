# 台灣節日祭祀日曆與紙錢小指南

本頁用民俗資料整理一年中常見的祭祀節點、目的與供品例子，方便第一次接觸的人先理解再詢問。**不是每個台灣家庭都拜，也沒有全台統一、人人必備的供品清單。**祭拜對象、日期、桌位、供品、紙錢及是否焚燒，會因宗教、家庭傳承、北中南地方習慣、廟宇和社區規定而不同；本頁描述習俗，不判定信仰真假，也不保證祭拜會帶來特定結果。

多數節日以農曆日期為主；清明、冬至依節氣，換算成國曆的日期每年不同。實際安排請看當年農民曆、家族通知或廟方公告。若家中平常沒有祭祀習慣，可以不做；想參加儀式時，先問家人或主辦廟宇「拜誰、何時、要準備什麼、紙錢怎麼處理」。

## 一年中常見的節日與祭祀節點

| 時間 | 常見目的或習俗 | 入門準備例子 | 提醒 |
| --- | --- | --- | --- |
| 農曆十二月二十四 | 送神；民俗上認為神明在年末返回天界述職，也有人謝神、清理神桌 | 茶水、簡單水果或甜食；是否準備紙錢依家中習慣 | 供品與祭拜時間各家不同；不必照網路清單買滿整桌 |
| 除夕至正月初一 | 圍爐、迎新年；有些家庭祭拜家神、祖先或地基主 | 家常年菜、水果、年糕或蘿蔔糕；依對象決定 | 先問家中長輩流程。除夕、初一、初二回娘家等作法都可能因家庭而異 |
| 農曆正月初九 | 部分家庭或廟宇祝壽天公（玉皇上帝） | 依廟方指示準備茶、水果或素供品 | 儀式可能較隆重，但不是每戶都在家祭拜；勿把某一套供桌當作普遍規定 |
| 農曆正月十五（上元） | 三元節之一；民間信仰常連結天官賜福，當天也是元宵節 | 水果、茶或簡單供品 | 廟宇儀式與家庭安排不同，有些人只過元宵、不另祭拜 |
| 農曆二月初二（頭牙） | 部分家庭、商家祭土地公，俗稱頭牙；不少商家也在每月初二、十六做牙 | 水果、茶、糕餅等簡單供品 | 供品種類依店家和地區不同；頭牙與每月做牙不是所有人的義務 |
| 清明節（節氣） | 掃墓、追思祖先；有些家庭也在家祭祖 | 鮮花、水果、茶水或家常供品 | 公墓、納骨塔與各地有不同祭掃、用火和清潔規定；先查管理單位公告 |
| 農曆五月初五（端午） | 過節、家人團聚；有些家庭會祭祖 | 粽子、水果或家常飯菜 | 不必因為端午就另買牲禮或紙錢，依家中傳承即可 |
| 農曆七月（普度日期依廟宇／社區） | 中元普度、普施等儀式；由廟宇、社區或公司安排日期 | 依主辦單位通知準備可分享的包裝食品、水果、飲料等 | 農曆七月的普度不一定在七月十五；確認桌位、供品收取時間、是否需報名及紙錢集中方式 |
| 農曆七月十五（中元） | 三元節之一；民間常以祭拜地官、普度為主題 | 家庭或社區常見水果、熟食、糕點、飲料等 | 儀式規模差異很大。不要擅自在道路、巷弄或公寓公共區域擺桌、燃燒或留下食物 |
| 農曆八月十五（中秋） | 團圓、賞月；部分家庭會祭月、土地公或家神 | 月餅、水果、茶水等 | 祭月與祭神的做法不一；注意烤肉煙霧、用火和垃圾清理 |
| 農曆九月初九（重陽） | 登高敬老；部分家庭會祭祖或合祭祖先 | 水果、糕點或家常供品 | 是否有重陽祭祖、供品豐簡均依家族傳承，不是全台固定流程 |
| 農曆十月十五（下元） | 三元節之一；部分廟宇祭祀水官或舉辦法會 | 若參加廟會，依廟方通知 | 一般家庭未必另行祭拜，不需要自行準備專門供品 |
| 冬至（節氣） | 團聚、吃湯圓；有些家庭以湯圓祭祖或謝冬 | 湯圓、茶水或家常供品 | 冬至國曆日期每年依節氣略有不同；祭祀是部分家庭習俗 |
| 農曆十二月十六（尾牙） | 商家或部分家庭歲末祭土地公、慰勞員工 | 水果、糕餅或公司聚餐 | 現代公司聚餐常稱尾牙；是否祭拜與宴客方式依公司和家庭安排 |

以上是方便辨認時序的例子，不是完整宗教年曆。像清明、端午、過年和重陽的祭祖方式，國史館臺灣文獻館資料也記錄了不同供品和地方差異；三元節、土地公頭牙尾牙、送神和謝冬則各有民俗記載。若參加法會或社區普度，主辦者的公告優先於通用整理。

## 金紙、銀紙怎麼入門

紙錢的稱呼與用途來自民俗傳承，不能只看名稱就推定所有地方都一樣。常見概念可先這樣理解：

| 常見名稱 | 民俗上的常見對象／用途 | 初學者怎麼做 |
| --- | --- | --- |
| 金紙（例如壽金、刈金等） | 常見於祭拜神明；種類可能按神祇、儀式或地方習慣區分 | 先問廟方或家人這次是否需要、要哪一種；不確定就先不買 |
| 銀紙（例如大銀等） | 常見於祭祖或普度等儀式；不同地區使用方法有差異 | 確認祭祀對象和收運方式，不要把某地做法當全台規則 |
| 經衣、往生衣、高錢等 | 某些祖先、普度、法會或特定儀式才會使用 | 只按主辦者指示準備，勿把它當成每個節日的基本套組 |

想簡化時，可以只準備家人會食用的水果、茶水或家常食物；也可以不燒紙錢，改用廟方接受的捐米、公益捐款或其他替代方式。**祭拜對象不同，不代表必須購買一整套金銀紙；燒紙錢也不是所有祭祀的必要條件。**

## 安全與環境友善做法

環境部推廣「新紙錢三燒」：

1. **替代燒：**以功代金、捐米或其他主辦者接受的方式表達心意。
2. **適量燒：**減少紙錢和香的數量，不為求完整而大量焚燒。
3. **集中燒：**使用廟方、清潔隊或地方政府提供的集中收運及合適設施。

在公寓、租屋處、陽台、樓梯間、道路或逃生動線點火前，先確認租約、社區規約、場所禁火規定和所在地公告；不要在室內或未設置安全設施的地方燒紙。保持消防通道暢通，紙灰和供品依場所指示處理，避免遺留垃圾、燙傷或引燃周遭物品。

## 第一次參加時的四步驟

1. **先問對象與主辦者：**是拜神明、祖先、地基主或參加普度？問家人、廟方、管委會或活動主辦者。
2. **確認時間與規則：**核對農曆日期、集合時間、桌位、供品是否由主辦者統一準備，以及可否焚燒。
3. **準備簡單且吃得完的供品：**考慮天氣、保存、過敏、慢性病飲食和寵物安全；不清楚紙錢種類時先不買。
4. **依規定收拾現場：**妥善收回供品與器具，紙錢交由指定地點處理，不阻塞通道或影響鄰居。

搬家或租屋入住時，有些家庭會拜地基主，也有家庭不做。這不是一般住宅租約的法定義務；先問屋主、管理室與家人，並遵守租約、社區規約和消防規定。
