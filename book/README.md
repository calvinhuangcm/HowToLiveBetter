## 台灣日常差異

- **倒垃圾前先查所在地路線。** 清運時間、收運點和回收日由地方路線安排。環境部提供全國查詢入口。不要把垃圾留在公共場所。
- **家裡準備能拿了就走的避難包。** 台灣需要考慮地震、颱風、淹水和停電。用品依家人、寵物、藥物和離家需求調整。
- **留住重要的政府與求助電話。** 119 處理火災、救護和急難救助；手機收訊不佳時可試 112。福利需求可問 1957，長照需求可打 1966。
- **照顧安排要看家人和地方資源。** 長照服務先由 1966 或所在地照管中心評估，不假設每個家庭都由同一位家人照顧。

更多在地生活提醒見[第 0 章：台灣日常生活](00-台灣日常生活.md)及[節日祭祀日曆與紙錢小指南](../docs/台灣節日祭祀日曆.md)。
